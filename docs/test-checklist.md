# Fresh QBCore baseline checklist

Use a fresh txAdmin profile and a test database.

1. Confirm the txAdmin recipe finishes and QBCore, oxmysql and Vanta resources start.
2. Join and confirm the Vanta loading screen shows connection progress and closes when the QBCore character selector appears.
3. Create or select a character and choose a spawn.
4. Confirm no target-eye prompt appears.
5. Walk near a test interaction registered with `vanta-ui`; confirm the bottom-left prompt appears.
6. Press **E** to open, use the mouse wheel to change selection, and press **Enter** to activate. Repeat using **Enter** to open and **E** to activate.
7. Press **F1** and confirm QBCore's radial opens.
8. Check both the server console and F8 client console for errors.
